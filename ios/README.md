# نسخة iOS — ما جُهِّز وما يلزمك

## ⚠️ الحقيقة أولاً: البناء يحتاج جهاز Mac

`flutter build ios` **ليس أمراً موجوداً على ويندوز إطلاقاً** — لا أنه
يفشل، بل Flutter لا يسجّله خارج macOS:

```
Could not find a subcommand named "ios" for "flutter build".
```

السبب أن ترجمة iOS تمرّ عبر **Xcode** و`xcodebuild`، وهما لا يعملان إلا
على macOS. لا توجد حيلة تتجاوز ذلك: لا إعداد ولا حزمة ولا سطر أوامر.

**خياراتك الثلاثة:**

| الخيار | التكلفة | ملاحظة |
|---|---|---|
| جهاز Mac (أو Mac mini مستعمل) | مرّة واحدة | الأسهل إن ستحدّث التطبيق كثيراً |
| **Codemagic** أو GitHub Actions بـ `macos-latest` | مجّاني جزئياً | يبني من المستودع مباشرةً — الأنسب لك |
| مستأجَر بالساعة (MacinCloud وأمثاله) | بالساعة | للتجربة الأولى |

وفي كل الحالات: نشر التطبيق على iPhone يتطلّب **حساب Apple Developer**
بـ99 دولاراً سنوياً. بدونه يمكن تثبيته على جهازك وحده لمدة **7 أيام** ثم
يتوقّف.

## ما جُهِّز لك بالفعل (يعمل فور فتحه على Mac)

- **منصّة iOS كاملة** في `ios/` بمعرّف الحزمة `com.kmsan.kmsan`.
- **أذونات `Info.plist`** — الكاميرا ومعرض الصور. ⚠️ هذه ليست تفصيلاً:
  iOS **يُنهي التطبيق فوراً** (crash لا رفض مهذّب) عند فتح الكاميرا بلا
  سبب مكتوب. مكتوبة بالعربية لأن الزبون يقرؤها.
- **العربية لغةً أولى** (`CFBundleDevelopmentRegion`) وإلا عرض iOS
  حوارات النظام بالإنجليزية على جهاز عربي.
- **الأيقونات الـ15** مولَّدة من الشعار نفسه بـ
  `dart run tool/generate_icons.dart` — بخلفية بيضاء لا شفافة، لأن
  App Store يرفض الأيقونة الشفافة وتظهر سوداء على الجهاز.
- **الكود آمن على iOS**: كل نداءات `dart:ffi` الخاصة بويندوز محروسة بـ
  `Platform.isWindows`، والمكتبات تُفتح **كسولاً** عند أول استعمال لا
  عند الاستيراد — فلا شيء منها يُنفَّذ على الآيفون.

## سلوك التطبيق على iPhone — مطابق لأندرويد تماماً

نفس الشيفرة ونفس قاعدة البيانات، فكل ما يحدث على الحاسوب يظهر على
الهاتف فوراً والعكس. الفروق الثلاثة **مقصودة وموجودة على أندرويد أيضاً**:

| الوظيفة | الحاسوب | iPhone وأندرويد |
|---|---|---|
| الطباعة | مباشرة على الطابعة | **يضع أمر طباعة** في `print_jobs`، فيطبعه حاسوب المحل بإعداداته ومعايرته |
| مسح الباركود | قارئ سلكي (يكتب ثم Enter) | كاميرا الجهاز |
| اختصارات لوحة المفاتيح | Enter / Space / Escape | لا تظهر أصلاً (لا لوحة مفاتيح دائمة) |

> ملاحظة: `mobile_scanner` **يدعم iOS** (بخلاف ويندوز حيث لا يعمل)، فمسح
> الباركود بالكاميرا يشتغل على الآيفون كما على أندرويد.

## الخطوات على جهاز Mac

```bash
git clone https://github.com/lhossohmida-lang/assil.git
cd assil
flutter pub get
```

**1. سجّل تطبيق iOS في Firebase** (لوحة Firebase ← إضافة تطبيق ← iOS):
- Bundle ID: `com.kmsan.kmsan` (يجب أن يطابق حرفياً)
- نزّل `GoogleService-Info.plist`
- ضعه في `ios/Runner/` **وأضفه إلى Xcode** بالسحب داخل مجموعة `Runner`
  مع تعليم *Copy items if needed*. ⚠️ نسخه بـ`cp` وحده لا يكفي — لا
  يدخل الحزمة فيفشل Firebase عند الإقلاع.

**2. ثبّت الاعتماديات الأصلية:**

```bash
cd ios && pod install && cd ..
```

**3. اختبر على جهاز موصول:**

```bash
flutter run --release
```

**4. ابنِ ملف التوزيع:**

```bash
flutter build ipa --export-method development
```

يخرج في `build/ios/ipa/`. للنشر على App Store استعمل
`--export-method app-store` بعد ضبط التوقيع في Xcode
(Signing & Capabilities ← فريقك).
