# فيديوهات صفحة الهبوط

ضع هنا أربعة ملفات بهذه الأسماء **بالضبط**:

| الملف | المشهد |
|---|---|
| `1-welcome.mp4` | الترحيب |
| `2-categories.mp4` | أنواع المنتجات |
| `3-fabric.mp4` | جودة القماش |
| `4-contact.mp4` | التواصل |

- صيغة **MP4 (H.264)**، رأسياً 1080×1920 أو مربّعاً 1080×1080.
- **بلا صوت** — الصفحة تشغّلها صامتة، والصوت يزيد الحجم بلا فائدة.
- 5–8 ثوانٍ لكل مقطع، ويُعاد تلقائياً.
- أبقِ كل ملف **تحت 3 ميغابايت**: الزبون يفتح الموقع على بيانات الهاتف.

إن غاب ملف تظهر خلفية بيج متدرّجة مكانه ولا ينكسر شيء.
